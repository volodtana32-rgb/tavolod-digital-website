# AI-ПРОДАКШН · Сайт-портфолио Тани Волод

Лендинг-портфолио для премиального AI-продакшена. Сайт визуально презентует восемь направлений услуг — от нейрофото и цифровых аватаров до авторской музыки, видео, брендинга, иллюстраций, копирайтинга, маркетплейсов и вайбкодинга.

## Какую задачу решает

Сайт решает задачу быстрой и запоминающейся презентации услуг автора AI-контента:

- **Собирает все направления в одном месте** — клиент сразу видит весь спектр услуг и может кликнуть нужную.
- **Демонстрирует портфолио** — каждое направление открывает модальную галерею с примерами работ (фото, видео, аудио).
- **Упрощает контакт** — кнопка «Написать мне» ведёт сразу в Telegram, есть ссылки на Telegram и VK.
- **Создаёт wow-эффект** — главная страница построена вокруг интерактивной 3D-спирали из карточек услуг, которую можно крутить мышью, тачем или колёсиком.
- **Работает на всех устройствах** — адаптивная вёрстка с отдельными превью для десктопа и мобильных устройств.

## Для кого (пользователь)

Сайт создан для потенциальных клиентов Тани Волод:

- **Частные клиенты** — люди, которым нужен необычный подарок, видео-поздравление, оживление фото или персональный образ.
- **Эксперты и блогеры** — авторы, которым важен выразительный визуал для личного бренда: нейрофотосессии, обложки, ролики, AI-контент.
- **Предприниматели и бренды** — владельцы бизнеса, которым нужен современный и запоминающийся визуал: логотипы, айдентика, имиджевые ролики, карточки товаров.
- **Заказчики премиум-упаковки** — те, кто хочет комплексную подачу проекта под ключ без студий, съёмок и долгих согласований.

## Технологии

- HTML5, CSS3, чистый JavaScript (vanilla JS)
- Google Fonts: Unbounded + Manrope

## Как открыть

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8000
```

Затем перейди по адресу `http://localhost:8000`.
